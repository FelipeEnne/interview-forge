# Changelog

## v0.1.0

First MVP release.

- **Study:** Active recall on 30 Node.js questions across 8 categories; Again / Hard / Good / Easy ratings; session summary; browser LocalStorage progress; fixed-interval review scheduling; due-question selection; weaker-question ordering; category practice.
- **Test:** Node.js Proficiency Quiz with 10 questions per attempt (from 20), 8-minute timer, attempt scoring with category breakdown, and accumulated per-category performance with weak-category hints on the topic page.
- **Practice:** Six Node.js coding challenges (async, APIs, middleware, errors, `Promise.allSettled`, streams) with reference solutions and review checklists; no code execution in the app.
- **Quality:** 107 automated tests; lint and production build passing.
